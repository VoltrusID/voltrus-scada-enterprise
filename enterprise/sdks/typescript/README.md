# @voltrus/enterprise-sdk

Private. Enterprise add-on endpoints for the Voltrus SCADA TypeScript SDK.
`VoltrusEnterpriseClient` extends the public `VoltrusClient`, so Core calls
and the Enterprise groups (`license`, `compliance`, `security`, `hub`,
`cameras`, `reports`, `branding`, `ha`, `sso`) share one session.

See [../README.md](../README.md) for the endpoint list, versioning and
development steps.
